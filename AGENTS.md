# AGENTS.md

Guidance for Codex CLI / other coding agents working in this repo.

## What this is

Phone→Mac realtime transcription + AI analysis pipeline. Android app does on-device Japanese speech recognition and sends only text segments (never audio) over a Tailscale tailnet to a Mac server (Fastify + SQLite), which runs `codex exec` on demand to produce summaries/advice/reply drafts. A web viewer lets other devices watch a session live.

## Layout

- `server/` — Node.js + TypeScript + Fastify 5 + better-sqlite3. REST API, web UI (`server/public/`), `codex exec` integration (`server/src/ai/codexProvider.ts`).
- `android/` — Kotlin + Jetpack Compose. Continuous `SpeechRecognizer` loop, segment queue with retry/backoff, analysis UI.

## Running the server

```bash
cd server
npm install
cp .env.example .env   # edit if needed
npm run build
npm start               # listens on 0.0.0.0:8787
# or for dev with watch:
npm run dev
```

Health check: `curl http://localhost:8787/healthz`

## Tests

```bash
cd server
npm test          # vitest, codex calls stubbed via fake script — run this normally
npm run test:live # hits real codex once; manual, not for routine use
```

## Android build

```bash
cd android
mv gradle/wrapper/wrapper.properties.tmp gradle/wrapper/gradle-wrapper.properties  # first time only
chmod +x gradlew
gradle wrapper --gradle-version 8.7   # needs a system Gradle 8.x/9.x
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Needs `android/local.properties` with `sdk.dir=...` (auto-generated by Android Studio).

## Important conventions / gotchas

- **HTTPS is the default for browser access, not HTTP.** The tailnet already has certs (`tailscale status --json` → `CertDomains`). Browsers block the Geolocation API on non-secure (HTTP) origins, so the viewer's location features require HTTPS. Publish it with:
  ```bash
  tailscale serve --bg --https=8443 http://localhost:8787
  ```
  (443 may be taken by another local project; 8443 is what's in use here). Resulting URL: `https://<machine>.<tailnet>.ts.net:8443/viewer.html?session=latest`. Check with `tailscale serve status`, undo with `tailscale serve --https=8443 off`.
- **HTTPS requires the MagicDNS hostname** — the cert is bound to it. The `http://100.x.y.z:8787` tailnet-IP fallback does NOT work over HTTPS. If MagicDNS isn't resolving (seen on iOS as `ERR_NAME_NOT_RESOLVED`), toggle the Tailscale VPN off/on to fix name resolution rather than falling back to the IP.
- Plain HTTP on port 8787 still works and is fine/expected for the Android app (not subject to the browser secure-context rule) and for quick local checks. Android's cleartext exception in `network_security_config.xml` is scoped to `ts.net` only.
- Browsers default the address bar to `https://`; when deliberately using the plain-HTTP endpoint you must type `http://` explicitly.
- Nothing here is exposed to the public internet — HTTPS via `tailscale serve` is tailnet-only, same as the plain HTTP endpoint.
- The server itself is a plain HTTP server; TLS termination for the browser path is handled entirely by `tailscale serve`, not by server code.
