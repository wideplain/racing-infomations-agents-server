## 指示

上記の会話ログとこれまでの記録**だけ**を根拠に、質問に答えてください。

- answer: 質問への回答。答えられる範囲だけを書く
- basedOn: 回答の根拠にした発言（配列）。各要素は `at`（根拠にした行の [mm:ss]。角括弧は付けず "12:34" の形式）と `quote`（その行の該当部分をそのまま引用）
- confidence: 回答全体への自信度（"low" | "medium" | "high"）
- unknown: 質問のうち、会話ログと記録からは答えられなかった点（配列）

重要な原則:

- **答えが出ないこと自体は問題ではありません。曖昧な答えが返ることが問題です。** 走行中のドライバーに「たぶん3周前です」と伝わるのが最も危険な失敗です。
- 数値（周回数、順位、タイム、燃料量など）や状態を、聞き取れていないのに推測で補ってはいけません。記録にないことは answer に書かず、unknown に「記録にありません」と明示してください。
- 一般的なモータースポーツの知識で補完してはいけません。この会話ログとこれまでの記録に無い情報は、すべて「記録にない」として扱ってください。
- 質問にまったく答えられない場合は、answer に「記録にありません」と書き、basedOn を空配列、confidence を "low" にしてください。取り繕った回答を返してはいけません。
- basedOn は、クルーが回答を電話でドライバーに伝える前に「本当にそう言っていたか」を突き合わせるためのものです。引用は言い換えず、ログの文言そのままにしてください。答えの根拠になった行だけを挙げ、関係のない行を並べないでください。
- **basedOn に挙げてよいのは会話ログの行だけです。** `at` には、その行に実際に付いている [mm:ss] をそのまま写してください。計算して求めたり、「これまでの記録」の実時刻を書いたり、存在しない時刻を書いたりしてはいけません。実在しない時刻はクルーの突き合わせを空振りさせるため、根拠として無意味です。
- 「これまでの記録」だけを根拠に答える場合は、その旨を answer に書き、basedOn には対応する会話ログの行があるときだけ入れてください。無ければ basedOn は空配列にしてください。
- 聞き取りが曖昧な箇所に依拠して答えた場合は、confidence を下げ、その旨を unknown に書いてください。
- 「(手修正済み)」の付いた行は、音声認識の結果より優先して信頼してください。

## 出力形式

**JSON のみ**を出力してください。前置きや説明文、コードフェンス（```）は不要です。以下のスキーマに厳密に従ってください。

```json
{
  "answer": "string",
  "basedOn": [{ "at": "12:34", "quote": "string" }],
  "confidence": "low",
  "unknown": ["string"]
}
```
