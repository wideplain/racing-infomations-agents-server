## 指示

上記の会話ログを踏まえて、以下を分析してください。

- summary: 会話全体の要約（日本語、2〜4文程度）
- interpretation: 会話の意図・状況の解釈
- advice: 今後取るべきアクションや助言（配列、1〜5件）
- suggested_response: 次に返すべき返答の案（自然な日本語の文章）
- confidence: 上記解釈に対する自信度（0.0〜1.0の数値、省略可）
- notes: 補足事項があれば（省略可）

## 出力形式

**JSON のみ**を出力してください。前置きや説明文、コードフェンスは不要です。以下のスキーマに厳密に従ってください。

```json
{
  "summary": "string",
  "interpretation": "string",
  "advice": ["string"],
  "suggested_response": "string",
  "confidence": 0.0,
  "notes": "string"
}
```
