## 指示

上記のログとこれまでの記録を踏まえて、以下の観点で整理してください。

- statusSummary: 現在の状況の事実整理（推測を含めない、聞き取れた事実のみ）
- change: 前回の記録からの変化点（変化がなければその旨を書く）
- question: 話者に確認すべき質問（曖昧な点や未確定の情報があれば具体的に）
- proposal: 軽い提案（あくまで参考情報であり、最終判断は話者に委ねる。命令形にしない）
- confidence: 全体の情報に対する自信度（"low" | "medium" | "high"）
- needsReview: 話者の確認が必要かどうか（true/false）
- facts: 聞き取れた事実の一覧（配列、確度の高いものだけ）
- warnings: 聞き取りが曖昧・不確実だった箇所（配列。曖昧な情報があれば必ず記載し、confidence を下げること）

重要な原則:

- 数値（周回数、順位、タイム、燃料量など）や状態を、聞き取れていないのに推測で補ってはいけません。不明な場合は facts に含めず、warnings に記載してください。
- 「事実」「変化」「確認すべき質問」「軽い提案」は明確に分離し、提案はあくまで参考であり、必ず話者の確認を待つものとして扱ってください。
- 「(手修正済み)」の付いた行は、音声認識の結果より優先して信頼してください。

## 出力形式

**JSON のみ**を出力してください。前置きや説明文、コードフェンス（```）は不要です。以下のスキーマに厳密に従ってください。

```json
{
  "statusSummary": "string",
  "change": "string",
  "question": "string",
  "proposal": "string",
  "confidence": "low",
  "needsReview": false,
  "facts": ["string"],
  "warnings": ["string"]
}
```
